Rebuild Instructions

        

          
          

            
              1. Blender — Rebuild Principled BSDF Material
              Interactive & Headless ▾
            
            

              
Automatically wires all extracted maps (Base Color, Metallic, Roughness, Normal Map, Specular, Transmission, Clearcoat, Sheen, Emissive) to Blender's Principled BSDF shader with correct color space settings (sRGB for color, Non-Color for data).


              
Interactive (Inside Blender GUI):

              
    
                
  1. Launch Blender (3.6+ or 4.x/5.x).
    2. 
                
  2. Switch to the Scripting workspace tab in the top header.
    3. 
                
  3. Click Open and choose blender_build_material.py (included in your extracted ZIP / output directory).
    4. 
                
  4. Set MANIFEST = "manifest.json" (or your full path to manifest.json) near line 32.
    5. 
                
  5. Click Run Script (▶) or press Alt+P.
    6. 
                
  6. Switch the 3D Viewport shading mode to Material Preview (Z > 2) to view the fully wired model!
    7. 
              


              
Headless (Terminal / CLI):

              

                blender --python blender_build_material.py -- --manifest manifest.json --glb model.glb --save model_shaded.blend
                
              

              

                Helpful Flags:

                • --displacement : Connects the 16-bit Height map to a Displacement node for microdisplacement in Cycles.

                • --ao-multiply : Multiplies the AO map directly into Base Color for extra cavity occlusion.

                • Omit --glb to build the material directly onto an inspection UV sphere.
              

            

          


          
          

            
              2. Substance Designer (Headless via SAT / pysbs)
              Batch .sbs package ▾
            
            

              
Headlessly compiles a native .sbs Substance Designer package containing a complete graph with linked bitmap inputs and standard output nodes (baseColor, metallic, roughness, normal, AO, height, emissive, opacity, scattering, sheen, coat), linking the OBJ mesh as a 3D scene resource.


              
Prerequisites:

              
Requires the pysbs Python module from the Adobe Substance Automation Toolkit (SAT):

              

                pip install "<SAT_PATH>/Python API/Pysbs-*.whl"
                
              


              
Batch CLI Command:

              

                python substance_build_sbs_pysbs.py manifest.json -o out.sbs --n2h
                
              

              

                Flags & Options:

                • --n2h : Uses Designer's built-in Normal to Height HQ node instead of the baked FFT height map (recommended for clean, artifact-free micro-details).

                • --normal gl|dx : Selects OpenGL (+Y) or DirectX (-Y) normal map convention.

                • -o <file.sbs> : Output file path (defaults to <model>_pbr.sbs).
              

            

          


          
          

            
              3. Substance Designer (In-App Python Editor)
              Live in Designer UI ▾
            
            

              
Runs directly inside an active Substance 3D Designer window, generating a new package in your workspace with your material graph and hooking up the 3D viewport.


              
Step-by-Step Instructions:

              
    
                
  1. Open Adobe Substance 3D Designer.
    2. 
                
  2. Go to Windows → Python Editor (or click the Python console button in the top toolbar).
    3. 
                
  3. Open substance_build_sbs_designer.py in the Python Editor (or paste the script contents).
    4. 
                
  4. Check line 36: ensure MANIFEST = "/path/to/manifest.json" has the full path to your manifest.json.
    5. 
                
  5. Click the green Run button (or press Ctrl+Enter / Cmd+Enter).
    6. 
                
  6. A new package will appear in the Explorer panel with the <Material>_pbr graph and linked bitmap resources.
    7. 
                
  7. View in 3D Viewport:
                  
    • In Explorer, right-click the imported OBJ scene resource → Show in 3D View.
                  
    • Right-click the graph → View outputs in 3D View.
                
    8. 
              

              

                Normal Convention Tip: If shading looks inverted in Designer's 3D view, check Materials → Default → Edit → Normal Format (switch between OpenGL and DirectX), or set NORMAL_CONVENTION = "dx" in the script.
